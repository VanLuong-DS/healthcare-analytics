LLMs & AI for Analytics

A practical introduction to prompts, agents and APIs—without treating AI output as a substitute for checking the data.

Write a useful prompt

A good prompt states the task, context, expected output, and constraints. Include a small example when formatting matters.

Task: Summarize the top three changes in monthly visits.
Context: This is synthetic medical claims data.
Output: Three bullets and a short caveat.
Constraints: Do not invent numbers; say when data is missing.

Use AI as an assistant, not a source of truth

LLMs can help draft SQL, explain errors, categorize free text and summarize results. Validate calculations and check whether the output is grounded in the source data.

Embeddings and retrieval

Embeddings represent text as vectors. Retrieval-augmented generation (RAG) searches relevant material first, then supplies it as context for an LLM answer. Source quality and access controls still matter.

What is an agent?

An agent combines a model with tools and a sequence of actions—for example, fetching a report, running a query and drafting a summary. Start with limited permissions, review steps and clear stopping conditions.

API basics for backend tasks

An API lets a program send requests and receive structured responses. Keep API keys in server-side environment variables, never in public GitHub Pages JavaScript.

import os
import requests

api_key = os.environ["MY_API_KEY"]
response = requests.get(
    "https://api.example.com/records",
    headers={"Authorization": f"Bearer {api_key}"},
    timeout=20,
)
response.raise_for_status()
records = response.json()

Illustrative endpoint only. A real backend service is required for protected APIs.

Healthcare data and privacy

Use fictional or properly approved data in examples. Do not paste patient-identifiable information into external AI services without appropriate authorization and safeguards.

Practice

Try rewriting a vague prompt into one with a clear task, data context, output format and validation rule.
