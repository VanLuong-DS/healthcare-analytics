Python for Everyday Analytics

A practical introduction to the Python tools I find useful for reading, cleaning, joining and summarizing data.

Read data with pandas

A DataFrame is a table with rows and columns. Start by checking the shape, column types, and missing values.

import pandas as pd
visits = pd.read_csv("data/visits.csv")
print(visits.shape)
print(visits.head())
print(visits.isna().sum())

Filter and create columns

Filter before calculating. Keep the logic easy to verify.

paid = visits.loc[visits["claim_status"] == "Paid"].copy()
paid["allowed_amount"] = pd.to_numeric(paid["allowed_amount"])
print(paid[["visit_id", "allowed_amount"]].head())

Group, summarize and sort

Groupby is the pandas equivalent of many SQL GROUP BY queries.

summary = (paid.groupby("diagnosis_code", as_index=False)
           .agg(visits=("visit_id", "count"),
                avg_allowed=("allowed_amount", "mean"))
           .sort_values("visits", ascending=False))
print(summary.head())

Join datasets

Join visits to providers to compare specialties. Check the number of rows before and after the merge.

providers = pd.read_csv("data/providers.csv")
joined = visits.merge(providers, on="provider_id", how="left")
print(joined.groupby("specialty").size())

NumPy basics

NumPy handles numerical arrays and vectorized calculations. It is useful for percentiles, conditional logic, and numerical operations.

import numpy as np
amounts = visits["allowed_amount"].to_numpy(dtype=float)
print(np.mean(amounts))
print(np.percentile(amounts, [25, 50, 75]))
